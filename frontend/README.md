# RoofDynamics — Frontend

React 19 + Vite 8 + TypeScript (strict) + Tailwind CSS v4 SPA for the
RoofDynamics ERP. Part of the [RoofDynamics monorepo](../README.md).

---

## Quick start

```bash
npm install
npm run dev          # http://localhost:5173 (proxies /api -> :5000)
npm run build        # tsc -b && vite build -> dist/
npm run preview      # serve the production build locally
```

Use the shared root scripts (`npm run dev`, `npm run install:all`) to run both
frontend and backend together.

## Key conventions

- **Routing:** `react-router-dom`; all pages lazy-loaded via `React.lazy` in
  `App.tsx`, wrapped in `<ErrorBoundary>` and `<Suspense>`.
- **Auth & guards:** module access via `<FeatureGate moduleKey="…">`, role
  access via `<RoleGuard permission="…">`.
- **Styling:** Tailwind v4 CSS-first tokens in `src/index.css` (industrial
  dark/slate palette); shadcn/ui primitives consume `var(--*)` tokens and theme
  switching via `.light-theme`.
- **Forms & tables:** shadcn/ui primitives; `DataTable` provides search, sort
  and pagination.
- **Offline:** mutations persist to `localStorage`/IndexedDB via
  `services/offlineSync.ts`; the PWA service worker is generated by
  `vite-plugin-pwa`.
- **Environment:** all `import.meta.env` reads go through `src/env.ts` (Zod).
  See [`../.env.example`](../.env.example).
- **Production API:** the Netlify demo has no hosted backend. `VITE_USE_SANDBOX_API=true`
  (in `.env.production`) routes every `api` call through
  `services/sandboxApi.ts` — seeded data plus localStorage-backed mutations.
  Keep it `false` locally to exercise the real Express API.
- **Icons:** Lucide React. **Charts:** Recharts. **PDF:** `@react-pdf/renderer`.

## Domain logic (hardcoded WA rules)

- `src/utils/roofBomCalculator.ts` — pitch factor, true area, sheet rolling
  schedule (mm cut lengths), batten stock lengths, insulation, fasteners
  (7/m² standard, 10/m² coastal + Darling Scarp), coastal corrosion upgrade,
  AS 3959 BAL-19/BAL-29 bushfire items.
- `src/utils/waComplianceEngine.ts` — 6.5% deposit cap (Home Building Contracts
  Act 1991), $20k builder rule + BA1/BA2 permits, plumber licensing, WorkSafe
  height/asbestos rules, SOP Act 15-business-day countdown.
